# ⛽ 油查查New

一款简洁、现代的**全国油价查询**微信小程序，支持按省份查看 92# / 95# / 98# 汽油及 0# 柴油的实时价格、涨跌幅度，并提供**全国油价排行榜**与**下次调价倒计时**。

> 数据来源于公开渠道，仅供参考，请以官方发布为准。

## ✨ 功能特性

- **省份油价查询**：首页按省份展示 92# / 95# / 98# / 0# 柴油价格，涨跌红绿标签 +「较上轮」
- **全国油价排行榜**：按油品类型一键切换，价格从高到低排列，前 3 名奖牌高亮，附最高/最低价汇总
- **下次调价倒计时**：自动推算下次调价时间并实时倒计时
- **智能省份选择**：首次进入全屏列表选择省份，支持搜索、选中高亮；自动记忆上次省份
- **快捷跳转**：排行榜 / 我的页点击省份，一键回到首页并选中该省
- **分享卡片**：分享好友 / 朋友圈，标题自动带上 92#/95#/98# 三种价格
- **深色模式**：跟随系统自动切换亮/暗主题，全页面适配
- **数据兜底**：网络异常时自动回退本地缓存 → 内置参考数据，保证可用性
- **我的页**：最近查看省份、数据更新时间、意见反馈、清除缓存、版本信息

## 🛠 技术栈

- **微信小程序原生框架**（无第三方 UI 框架，WXML / WXSS / JS）
- 数据请求：`wx.request` + 60s 请求节流
- 三级数据回退：**API → 本地缓存 → 内置默认数据**
- 主题：CSS 变量 + `prefers-color-scheme` 深色模式 + `theme.json` 系统主题

## 🚀 快速开始

1. **克隆项目**
   ```bash
   git clone https://github.com/zh1300/oil-weapp.git
   cd oil-weapp
   ```

2. **导入微信开发者工具**
   - 打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   - 选择「导入项目」，目录指向本项目根目录
   - 填入你的小程序 AppID（无 AppID 可选「测试号」）

3. **编译运行**
   - 点击「编译」即可预览，支持真机调试
   - 开发者工具 → 详情 → 本地设置可开启「模拟深色模式」查看暗色效果

## ⚙️ 配置说明

### 数据接口

本项目**不内置数据源**，油价数据接口需由开发者自行接入。

在 `utils/api.js` 中将 `BASE_URL` 替换为你自己的接口地址：

```js
const BASE_URL = 'https://your-api.example.com/oilPrice'; // TODO: 替换为你的数据接口
```

接口需返回如下结构（`code` 为 `200` 表示成功）：

```json
{ "code": 200, "data": [{ "regionName": "北京市", "date": "2026-07-18", "n92": 7.42, "n92Change": 0.24, ... }] }
```

> 提示：接口不可用时，小程序会自动回退到本地缓存与内置参考数据（`utils/provinces.js` 中的 `DEFAULT_OIL_DATA`）。

### 深色模式

- `app.json` 已开启 `"darkmode": true` 并配置 `"themeLocation": "theme.json"`
- 组件层颜色通过 `app.wxss` 中的 CSS 变量控制，可在 `theme.json` 与 `@media (prefers-color-scheme: dark)` 中统一调整

### 意见反馈

「我的」页意见反馈中的联系方式为占位内容，位于 `pages/mine/mine.js`，请替换为真实信息。

## 🧩 数据字段说明

| 字段 | 含义 |
|------|------|
| `regionName` | 省份名称 |
| `date` | 数据日期 |
| `n92` / `n92Change` | 92# 汽油价格 / 较上轮涨跌 |
| `n95` / `n95Change` | 95# 汽油价格 / 较上轮涨跌 |
| `n98` / `n98Change` | 98# 汽油价格 / 较上轮涨跌 |
| `n0` / `n0Change` | 0# 柴油价格 / 较上轮涨跌 |
